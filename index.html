About Me

Passionate developer with a drive for innovation and excellence

I'm a Computer Science explorer with a passion for crafting creative digital solutions and diving into intricate problems. Armed with a solid theoretical foundation in data structures, algorithms, and software engineering, I love bringing ideas to life through full-stack web development. My journey recently took me deep into building a secure, role-based LMS portal, where I got to tackle features like user management, attendance tracking, fee processing, and library cataloging, powered by technologies like Next.js, React, PostgreSQL, Prisma, MinIO, and NextAuth.js.

Beyond that, my projects span a fun range, from developing an AI/hardware-integrated bot for reconnaissance, crafting responsive event and conference websites using HTML, CSS, and JavaScript/React, to contributing to collaborative efforts like a retro-style CTF event site with Supabase and Google OAuth and upgrading large websites with Next.js 13 and the App Router. My toolkit is packed with languages like Python, C++, and Java, and a strong web stack including Next.js, React, Node.js, PostgreSQL, Supabase, Tailwind CSS, and Prisma.

I thrive on leveraging a robust tech stack to build applications that truly deliver exceptional user experiences and meaningful results. I'm always eager to learn new technologies and contribute to exciting, impactful projects.
